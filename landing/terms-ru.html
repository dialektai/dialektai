3. Сервисы

3.1 Описание

Продукт представляет собой настольное приложение, обеспечивающее интерфейс взаимодействия с большими языковыми моделями. Продукт работает преимущественно на Локальном устройстве Авторизованного пользователя. Компонент dialekt-cloud обеспечивает только валидацию лицензий, управление Учётной записью и выставление инвойсов.

3.2 Модель локального исполнения

По архитектуре Продукта промпты, ответы, история переписки и файлы, обрабатываемые через Продукт, остаются на Локальном устройстве Авторизованного пользователя, если Авторизованный пользователь не активировал явно Облачного LLM-провайдера. При активации Облачного LLM-провайдера промпты передаются напрямую с Локального устройства в API такого провайдера. Они не проходят через dialekt-cloud.

3.3 Облачные LLM-провайдеры не входят в состав Сервисов

При активации Клиентом или Авторизованным пользователем Облачного LLM-провайдера отношения между Авторизованным пользователем и таким провайдером регулируются исключительно собственными условиями обслуживания, политикой конфиденциальности и соглашением об обработке данных провайдера. dialekt не является стороной этих отношений и не выступает в качестве реселлера, агента или обработчика для Облачных LLM-провайдеров. Клиент несёт ответственность за:

  • принятие условий каждого Облачного LLM-провайдера, который он использует;
  • получение API-доступа (и оплату любых сборов) для каждого Облачного LLM-провайдера, который он использует;
  • обеспечение соответствия использования каждого Облачного LLM-провайдера применимому законодательству юрисдикции Клиента.

3.4 Обновления и изменения
