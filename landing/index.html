01 · The difference

Chat tools answer questions.
dialekt finishes the task.

A chat is a conversation. An agent is a loop — it reads, reasons, runs tools, checks its work, and keeps going. The output is not prose. The output is your code, changed.

Chat · answers

Chat

Asks the question. Gets a sketch. You still have to: open the file, paste, fix the syntax, run the tests, debug, repeat.

Agent · completes

Agent

Reads files. Runs tools. Writes the diff. Asks permission. Runs the test. Iterates until green. You stayed in the composer.

03 · Local by design

Your code stays on disk.
Not as a promise. As a wire.

04 · What it can do

A tool, not a toy.
Every capability is one it actually has.

Index

Read your codebase.

Semantic search across the workspace. Files are indexed locally on first open and kept in sync as you edit.

Exec

Run tools.

fs, grep, exec, git, plus MCP servers for github, postgres, linear, figma. Bring your own.

Edit

Edit files.

Every write is a diff. Preview, review, undo. Nothing leaves the review drawer without your keystroke.

Test

Run tests.

Execute, capture stdout, read the failure, iterate. The agent keeps going until green — or tells you it can't.

Drive

Drive the browser.

A headed Chromium the agent can navigate, click, type into. Useful for anything that lives behind a login.

Coming in 0.9
Swap

Switch models.

Llama, Qwen, DeepSeek, Mistral — any Ollama model. Swap mid-session. 42 GB loaded in ~11 s on NVMe.
