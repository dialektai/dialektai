Threat model

dialekt is a desktop application with optional cloud licensing. The threat model has two halves:

  • Local: the app runs on your machine. We protect your API keys (cloud LLM credentials) in your OS keychain, sandbox the agent's filesystem and shell access, and require explicit consent for destructive operations.
  • Cloud: the licensing service stores tenant metadata (company, email, plan, expiry, invoices) — no prompts, no agent outputs, no source code. Compromise impact: tenant list disclosure, not user data.

Local security measures

  • API keys for cloud LLM providers stored in OS keychain (GNOME Keyring / KDE Wallet on Linux, macOS Keychain, Windows Credential Manager). Fallback: AES-256-GCM file with scrypt-derived key from hostname+user.
  • Local backend listens on localhost:8765 only — no network exposure.
  • Tri-state permission system (allow / ask / deny) for filesystem, shell, browser, screen capture, mouse/keyboard, keychain.
  • Per-tool MCP consent: any destructive call asks before first use, with optional session-scoped trust.
  • Code execution in sandboxed Python/shell environments via Open Interpreter.

Cloud security measures

  • Postgres encrypted at rest (filesystem-level on the host).
  • Cloudflare Tunnel for transport — no public ingress on the origin.
  • HTTPS everywhere (TLS 1.3).
  • Bearer tokens (JWT, HS256) with 24h TTL; secret rotation supported.
  • Role-based access (admin / owner / user).
  • Founder admin actions logged to founder_admin_log with full audit trail (3-year retention).
  • Daily Postgres backups, 7-day rolling.

Build & supply chain

  • Releases built reproducibly on GitHub Actions; artifacts SHA-256-tagged.
  • Signed builds for macOS (Apple Developer) and Windows (Authenticode) — in progress.
  • Linux installer fetches the upstream Ollama install.sh with SHA-256 pin verification before exec.
  • npm audit / pip audit run on every PR.

Vulnerability disclosure

Found a vulnerability? Email security@dialekt.ai. We respond within 72h. Coordinated disclosure preferred — give us 90 days before public write-up.
