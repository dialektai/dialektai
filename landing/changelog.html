v0.21.0 25 APR 2026 MAJOR

Cloud-LLM expansion: 18 providers joined Ollama. New onboarding picker with search, categories, Linux auto-install. Self-serve trial signup launched.

Added

  • 18 cloud LLM providers — Anthropic, OpenAI, Gemini, Vertex AI, AWS Bedrock, Azure OpenAI, NVIDIA NIM, Mistral, DeepSeek, xAI Grok, Cohere, Groq, Together AI, Fireworks AI, Perplexity, OpenRouter, Cerebras, Replicate
  • 33 curated Ollama models with category filters and RAM-fit indicators
  • Linux auto-install for Ollama with SHA-256 verified script and live SSE log stream
  • Self-serve 30-day trial via /signup — verify email, get a real cloud-issued license
  • Admin /admin/tenants/:id/extend — combined extend + grant-free-year
  • regulated_mode setting hides cloud tab for KZ ПДн compliance

Changed

  • Settings model_provider field — backward-compatible migration
  • Open Interpreter routing now goes through resolve_litellm_model (P0 bug fix: cloud selections used to silently revert to Ollama)
  • Onboarding screen rewritten with tabs and live filters

Fixed

  • Live model swap on websocket honours the current provider
  • pick_model_for_agent short-circuits in cloud mode
