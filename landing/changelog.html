  • MCP prompt now actually triggers tool calls; agents stop ignoring registered tools

  • Settings keychain values cached on load — fewer prompts on app start
  • build: grpcio compile unblocked on Windows ARM64 (MAX_PATH C1083); sqlite-vec skipped on Windows ARM64 where no wheel exists
