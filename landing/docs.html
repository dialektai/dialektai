Getting started

dialekt is a local-first desktop AI agent. The fastest path: install, paste your trial key, pick a model, give it a task. This page walks through that in ~5 minutes.

Install

Download links are sent to your inbox after you start a free trial. We deliver native builds for Linux, macOS, and Windows in one email — pick your platform, install, paste the trial key.

  • Linux — .deb for Debian/Ubuntu, .AppImage for everything else
  • macOS — .dmg · Apple Silicon · 12.0+
  • Windows — .exe installer · 10/11 · x64

16 GB RAM minimum. 48 GB recommended for 32B-class models.

License & trial

The first launch shows the License screen. Two paths:

  • Have a key — paste it. Validated against the licence service. The key arrives in the welcome email after signup.
  • Don't have one yet — go to /signup. 30 days, 3 seats, all features. Verify your email, paste the key, you're running.

Picking a model

The onboarding picker has two tabs:

Local · Ollama

33 models curated. Search by name, filter by category (General · Reasoning · Coding · Vision · Embeddings · Lightweight · Frontier). Each card shows RAM fit against your machine. We auto-rank: installed-and-fits → fits → unknown → too big.

Recommended starters by RAM:

  • 8 GB — llama3.1:8b or qwen3:8b
  • 16 GB — qwen3:14b or qwen2.5-coder:14b for coding
  • 32 GB+ — llama3.3:70b or qwen2.5-coder:32b

Cloud · Providers

18 providers — Anthropic, OpenAI, Google Gemini, Vertex AI, AWS Bedrock, Azure OpenAI, NVIDIA NIM (build.nvidia.com), Mistral, DeepSeek, xAI Grok, Cohere, Groq, Together AI, Fireworks AI, Perplexity, OpenRouter, Cerebras, Replicate.

Click a provider → enter API key → "Test connection" sends a 1-token completion → "Save & use". Keys are stored in your OS keychain (GNOME Keyring / macOS Keychain / Windows Credential Manager). Never sent to dialekt-cloud.

MCP servers

dialekt speaks the Model Context Protocol. Add servers from Settings → MCP → Add server. Common ones:

npx -y @modelcontextprotocol/server-filesystem
npx -y @modelcontextprotocol/server-slack
uvx mcp-server-postgres

Per-tool consent: any MCP tool that writes / executes / spends money asks before the first call, with a "remember for this session" option.

Building agents

Agents = a manifest YAML + a system prompt + a list of tool capabilities. Two ways to create:

  • 9-step wizard — Settings → Agents → New. Walks through goal, model preference, MCPs, permissions, schedule.
  • Import YAML — paste an existing manifest. Schema versioned via dialekt-manifest-validator.

Permissions

Six capabilities, tri-state per:

  • Filesystem — paths you select; sandboxed by default
  • Terminal — shell access; ask-per-command by default
  • Browser — Chromium drive (coming v0.9)
  • Screen capture — opt-in, ask-per-call
  • Mouse & keyboard — off by default; powerful, stays sealed
  • Keychain — sealed; never accessible to agents

CLI

Everything the desktop UI does is also a local HTTP API on localhost:8765. Useful for scripting:

curl http://localhost:8765/llm/catalog | jq '.providers[].id'
curl -X POST http://localhost:8765/settings -H 'Content-Type: application/json' \
  -d '{"model_provider":"anthropic","model":"claude-opus-4-7"}'

Troubleshooting

Ollama not detected

The install screen auto-runs curl -fsSL https://ollama.com/install.sh | sh on Linux (with consent + SHA verify). On macOS/Windows it opens the download page and polls.

License "not valid" right after signup

You haven't clicked the verify-email link yet. Check your inbox; spam folder; resend from /signup if needed.

Cloud provider returns 401

Test connection in the credentials modal. Most common: API key has trailing whitespace, or wrong project ID for Vertex AI / Bedrock.
